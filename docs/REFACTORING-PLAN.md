> **对标产品：** Gossip Harbor（日收50万刀）、Merge Mansion、Royal Kingdom
> **状态：** 待实施

---

## 一、专家级审计：原方案的问题

### 🔴 P0 — 三个致命问题

#### 问题A：玩家不知道棋盘会「死锁」

**实测场景：** 玩家合成到一半，棋盘填满 36 格，所有空位被占，无法移动，无法合并，只能等系统自动生成新物品填充空隙。

**后果：** 挫败感爆棚。玩家认为是 Bug，实际上是设计缺陷。

**修复：** 必须增加「出售物品」功能。任意物品可以消耗一定金币/能量，转化成 1-2 个随机低品物品，给棋盘腾出空间。这不是可选功能，是核心 QoL。

---

#### 问题B：L4 合成路径是「人工拖延」

**原方案问题：** 7 次同类型合并才能 L4。每次合成之间毫无变化，只有「叮」一声和 +500 金币数字跳出来。

**专家意见：** 玩家不怕重复操作，怕的是**重复操作没有进度感**。

**正确做法：**
- L4 合成应该有一个「传说时刻」—— 不是因为稀有，而是因为这是玩家第一次触碰到「故事核心道具」
- 融合系统（L3+任意L3=L4）是 **必须的**，不是锦上添花。它让玩家有策略选择：「我应该囤同类型，还是随便融合？」
- 增加「品阶进度条」：每个物品格子显示距离下次合成还要几个同级物品

---

#### 问题C：证据系统的「Teaser」太重

**原方案问题：** 3 秒片段 + 打字机效果 + 半屏遮罩 = 强迫看剧。

**专家意见：** 休闲游戏玩家 **最讨厌被强迫**。Teaser 必须轻量、可跳过、有吸引力。

**正确做法：**
- Teaser 文本直接浮在棋盘上 2.5 秒，然后飘走，不打断操作
- 给玩家选择：「🔍 线索已存入日志」可点击查看，也可忽略继续玩
- 第 3 个碎片才触发正式解锁动画（这时候玩家有期待，不会觉得烦）

---

### 🟡 P1 — 留存核心问题

#### 问题D：没有「明天回来」的动机

**现状：** 玩家清空今日订单后，没有理由打开游戏。

**专家意见：** Daily Engagement 不是靠「内容不够」来留人，而是靠「今天完成了什么 + 明天会有什么新东西」的期待感。

**修复清单：**
1. **每日登录奖励**（第 1-7 天递增）
2. **每日首次传说订单双倍掉落**（如果那天有传说订单）
3. **订单过期时间戳**（玩家知道「还有 14 小时订单就刷新了」）
4. **下一章预告**（故事进度 80% 时解锁，显示「第三章：遗书之谜」预告）

---

#### 问题E：能量系统视觉压迫感不足

**现状：** 能量低时只有一个灰色 overlay。

**专家意见：** 能量条是最强的 FOMO 机制，要让玩家在 UI 上 **一眼就能看到** 能量状态，而不需要专门去找。

**修复：**
- 顶栏能量条：满能量 = 金色发光；<30% = 红色脉冲；0% = 闪烁 + 震动
- 能量购买按钮：在棋盘正下方常驻显示，低能量时自动放大

---

### 🟢 P2 — 体验优化

#### 问题F：订单描述太平淡

**原方案修复方向正确，但执行不够彻底。**

**专家意见：** 悬念风格订单的黄金法则：**每条描述 = 一个问题的碎片**。

```
❌ 修复全家福照片
✅ "父亲站在照片最右边...他身边本来是谁？"

❌ 收集水晶碎片
✅ "水晶里映出的不是我的脸。是另一个女人。"

❌ 制作万能钥匙
✅ "这把钥匙能打开什么？保险箱...还是真相？"
```

---

#### 问题G：房间解锁没有「预告」

**现状：** 直接播放过场。

**专家意见：** 玩家解锁新房间的快感 = **神秘感（不知道里面有什么）** + **期待感（终于可以看了）** + **成就感（是我努力换来的）**。

**正确节奏：**
```
证据收集到 3/3
  → 棋盘中央出现房间 Icon（放大动画）
  → "📚 书房已解锁" 淡入文字
  → 2秒后 → "点击继续" 按钮出现
  → 点击 → 播放过场
```

---

### 🟡 补充：原方案遗漏的关键功能

#### 缺失 1：新手引导（Tutorail）

**现状：** 没有教程。

**风险：** 休闲游戏玩家 70% 在前 30 秒决定是否继续玩。如果开局不清楚 Merge 玩法，会直接流失。

**修复：** 首次打开游戏时，3 步引导：
1. 「拖动相同物品合并它们」→ 高亮一个 L1 物品，引导拖拽到另一个
2. 「合并升级获得金币」→ 高亮合成结果
3. 「点击订单完成任务」→ 高亮右侧订单面板

---

#### 缺失 2：「出售物品」按钮

**现状：** 棋盘满了只能等，无法主动清理。

**修复：** 棋盘右下角添加「整理」按钮：
- 花费 10 金币 → 自动把棋盘物品向左下角压缩（空出右上角）
- 花费 30 金币 → 随机清除 3 个 L1 物品

---

#### 缺失 3：剧情触发节点不清晰

**现状：** 玩家不知道完成多少订单才能看到下一段剧情。

**修复：** 订单面板显示「剧情进度：68% → 下一章节在 8 个订单后解锁」，给玩家目标感。

## 二、完整实现方案 v3.0

### 核心循环 v3.0

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│   合并物品 ───→ 获得金币 ───→ 完成订单                     │
│      ↑              ↑            ↓                        │
│      │              │      获得金币+能量                    │
│      │              │            ↓                        │
│      │              │      L4订单 ──→ 40%掉落证据碎片       │
│      │              │            ↓                        │
│      │              │      3个碎片 ──→ 解锁房间           │
│      │              │            ↓                        │
│      │              │      播放过场 ──→ 揭示秘密           │
│      │              │            ↓                        │
│      │              │      下一章节 ──→ 重复循环           │
│      │              │                                    │
│      └────── 能量 ◄──┘  (能量驱动合并频率)               │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 融合系统（快速升级路径）

| 配方 | 结果 | 触发时机 |
|------|------|---------|
| 同类型 L3 + 同类型 L3 | 同类型 L4 | 精准合成 |
| 任意 L3 + 任意 L3 | 随机 L4 | 融合（UI提示"融合成功！"） |

**注意：** 融合时，随机结果在「同类型 + 随机各 50%」之间选择，让玩家有策略博弈空间。

---

### 传说时刻（L4 合成特效）

```
触发条件：任意方式合成 L4 物品

Phase 1 (0-300ms)：屏幕中央出现白色闪光遮罩，物品从原位飞向屏幕中心
Phase 2 (300-600ms)：金光从中心扩散 + 物品放大 + 传说音效
Phase 3 (600-1500ms)：「传说物品获得！」弹窗显示物品 Emoji + 名称
Phase 4 (1500ms)：弹窗消失，物品回到棋盘，继续游戏
```

---

### 证据 Teaser（轻量版）

```
第1个碎片：
  → 棋盘右上角飘出小卡片「🔍 线索：1/3」（2.5秒后自动消失）
  → 点击卡片可查看完整 teaser 文本（2秒打字机效果）

第2个碎片：
  → 同样方式显示「🔍 线索：2/3」
  → teaser 文本更具体

第3个碎片：
  → 房间 Icon 放大动画 + 「📚 书房已解锁」
  → 「点击继续」按钮
  → 播放完整过场
```

## 三、数据结构改动

```typescript
// 证据碎片（带 teaser 文本）
interface Evidence {
  id: string;
  type: 'key' | 'photo' | 'crystal';
  roomId: string;
  teaserText: string;      // 新增：第1个碎片的悬念文字
  revealText: string;     // 新增：第2个碎片的关键线索文字
  teaserShown: boolean;    // 第1个 teaser 是否已展示
  revealShown: boolean;    // 第2个 reveal 是否已展示
  obtained: boolean;
}

// 传说订单
interface LegendaryOrder {
  id: string;
  description: string;       // 悬念风格
  requirements: Requirement[];
  rewardCoins: number;        // 800-1200
  energyCost: number;         // 40-60
  expiresAt: number;          // timestamp
  doubleEvidence: boolean;    // 完成时是否双倍掉落
  available: boolean;
}

// 每日登录记录
interface DailyReward {
  lastLoginDate: string;     // 'YYYY-MM-DD'
  currentStreak: number;      // 连续登录天数
  claimedToday: boolean;      // 今日是否已领取
  legendaryRefreshers: number; // 累计的传说刷新券
}

// 房间（带 teaser 动画数据）
interface Room {
  id: string;
  name: string;
  description: string;         // Teaser 悬念描述
  teaserText: string;          // 第1个碎片时显示的悬念
  requiredEvidenceCount: number;
  unlocked: boolean;
  teaserCutsceneId: string;    // 部分证据时播放
  fullCutsceneId: string;      // 全部收集后播放
  chapter: number;
  icon: string;
}
```

## 四、变现设计（内嵌，非弹窗）

| 触发点 | 机制 | 用户价值 |
|--------|------|---------|
| 能量 = 0 | 「看广告 +30 能量」（每日 8 次） | 免费续航 |
| 能量低（<20%） | 金币购买能量弹窗（100金币=+30） | 中等付费 |

| L4 合成 | 传说时刻顺带提示「传说订单需要 L4」 | 自然导流 |
| 棋盘满了 | 「整理棋盘」按钮（10金币） | QoS |
| 溢出金币 | 扭蛋入口（200金币=随机L1-L3） | 鲸鱼消耗 |

## 六、最小可行版（MVP，先跑通核心循环）

如果想先验证「合成→传说时刻→证据→剧情」是否吸引人，先做：

```
Phase 1（融合 + 传说时刻）   → 2小时
Phase 2（Teaser + 房间解锁） → 2小时
                               ────
总计：                        4小时
```

核心问题回答：**玩家会不会因为传说时刻而截图分享？会不会因为 Teaser 碎片想继续玩？**

这两个问题的答案，决定了游戏是否有传播力和留存力。

## 七、验收标准

| 功能 | 验收条件 |
|------|---------|
| 融合系统 | 任意 L3+L3 能合成 L4，UI 有「融合」提示 |

| Teaser | 碎片收集 → 2.5 秒飘字，不打断操作，可跳过 |
| 房间解锁 | 3/3 碎片 → 动画 + 过场，流畅无卡顿 |
| 新手引导 | 首次打开 → 3 步引导，30 秒内理解核心玩法 |
| 每日奖励 | 再次打开 → 弹窗显示登录天数和奖励 |
| 传说订单 | 每日出现 → 带倒计时，有紧迫感 |
| 能量视觉 | 能量 0% → 红色脉冲 + 震动 + 购买弹窗 |
